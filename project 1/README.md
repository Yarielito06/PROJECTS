# 🕵️ CASEFILE — The Digital Detective

A text-based detective investigation game built with Python.

## About the Project

CASEFILE is an interactive mystery game where players investigate suspects, analyse fictional evidence scores, and attempt to solve the case of a missing confidential document.

This project was created to practise Python programming, object-oriented programming, and problem-solving.

## Features

- Interactive investigation menu
- Multiple suspects with individual profiles
- Evidence analysis using Python dictionaries
- Suspect search and input validation
- Accusation system with different outcomes

## Technologies

- Python 3
- Object-oriented programming (OOP)
- Python standard library

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python3 main.py`
